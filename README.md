# Database Management Systems

Coursework and practical exercises for Database Management Systems (DBMS), including SQL labs, database scripts, MongoDB exercises, PL/SQL examples, task documents, and supporting PDFs.

## Repository Structure

- `lab_tasks/lab_01/` — Lab 1 SQL files and documents.
- `lab_tasks/lab_02/` — Lab 2 SQL files and documents.
- `lab_tasks/lab_03/` — Lab 3 SQL files and documents.
- `lab_tasks/lab_04/` — Lab 4 SQL files and documents.
- `lab_tasks/lab_05_joins/` — Lab 5 materials on SQL joins.
- `lab_tasks/lab_07/` — Lab 7 document.
- `lab_tasks/lab_08/` — Lab 8 DDL scripts and lab document.
- `lab_tasks/lab_09_triggers/` — Lab 9 materials on triggers.
- `lab_tasks/lab_10_transactions/` — Lab 10 transaction materials.
- `mongodb/lab_11_12/` — MongoDB lab manuals and task PDF.
- `pl_sql/` — PL/SQL scripts and supporting PDF materials.

- `quizzes/` — Quiz 1 and Quiz 2 papers.

## Working with SQL Files

Open `.sql` and `.ddl` files in your database client or SQL editor. The exact steps to execute them depend on the database system and setup used for each lab. MongoDB tasks may require a MongoDB environment and its query language.
